# Piyush Saini Portfolio

Recruiter-friendly full-stack portfolio inspired by the provided design references.

## Stack

- **Frontend:** Next.js, Tailwind CSS, Framer Motion
- **Backend:** Node.js, Express
- **Database:** MongoDB

## Run locally

1. Install dependencies

```bash
npm run install:all
```

2. Add your MongoDB URI in `backend/.env`

3. Start the API

```bash
npm run dev:backend
```

4. Start the portfolio

```bash
npm run dev:frontend
```

5. Open [http://localhost:3000](http://localhost:3000)

## Resume

Place your PDF at `frontend/public/resume.pdf` so the Download Resume buttons work.
